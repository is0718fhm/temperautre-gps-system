ようこそ

本システムは Raspberry Pi を用いて水温および位置情報を取得する計測システムです。 取得したデータはスマートフォンからリアルタイムで確認でき、CSVファイルとして保存することができます。

システム概要

本システムは次の機器で構成されています。

  • Raspberry Pi
  • GPSモジュール
  • DS18B20水温センサ
  • モバイルバッテリー
  • スマートフォン（操作用）

利用の流れ

  1. キットを設置する
  2. 電源を接続する
  3. スマートフォンをWi-Fiへ接続する
  4. Webページへアクセスする
  5. 計測開始ボタンを押す
  6. 計測終了後にCSVを保存する
