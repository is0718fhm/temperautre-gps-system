システム全体

本システムは Raspberry Pi を中心として、水温センサ、GPSモジュールおよびモバイルバッテリーで構成されています。

番号 名称 役割

② GPSモジュール 位置情報および時刻を取得します。

④ モバイルバッテリー システムへ電源を供給します。

各部の説明

① Raspberry Pi

システム全体を制御するコンピュータです。GPSおよび水温センサから取得したデータを処理し、スマートフォンへ送信します。

② GPSモジュール

現在位置およびGPS時刻を取得します。起動直後は測位完了まで数分かかる場合があります。

③ DS18B20水温センサ

金属製のセンサ部を水中へ入れて使用してください。ケーブル接続部は水に浸さないでください。

④ モバイルバッテリー

USBケーブルで Raspberry Pi に接続して使用します。残量が少ない場合は計測前に充電してください。

⑤ 防水ケース

使用前に蓋が確実に閉まっていること、およびケーブルグランドが十分に締め付けられていることを確認してください。

⑥ 防水グランド

使用前に緩みがないようにしっかりとしめてあることを確認してください。

配線

この節を読む前に

配線の確認や組み立ては、システムの管理者が行ってください。 通常の計測では配線に触れる必要はありません。

配線作業は必ず電源を切った状態で行ってください。 通電したままケーブルを抜き差しすると、Raspberry Pi やセンサが故障する原因になります。

水温センサの配線

DS18B20 は 1-Wire という方式で接続します。 データ線と電源（3.3V）の間に 4.7kΩ のプルアップ抵抗が必要です。 この抵抗がないと、水温が正しく読み取れません。

GPSモジュールの配線

GPSモジュールは UART というシリアル通信で接続します。 送信と受信を入れ違いに接続する点に注意してください。 Raspberry Pi の送信（TXD・8番ピン）はGPSの受信（RXD・緑線）へ、 Raspberry Pi の受信（RXD・10番ピン）はGPSの送信（TXD・橙線）へつなぎます。

電源は 5V（4番ピン）から供給します。水温センサは 3.3V なので、 配線時に取り違えないよう注意してください。 また、GPSモジュールの PPS 出力（茶線）を 12番ピンへ接続しています。

GPSモジュールから出ている5本の線は、データシートで次のように定められています。

線の色 信号名 内容 接続先
赤 VCC 電源（3.0〜5.5V） 4番ピン（5V）
黒 GND グランド 6番ピン（GND）
橙 TXD GPSからの送信 10番ピン（RXD）
緑 RXD GPSへの受信 8番ピン（TXD）
茶 PPS 秒パルス出力 12番ピン（GPIO18）

PPS（秒パルス）とは

PPS は Pulse Per Second（毎秒1回のパルス）の略で、 GPSモジュールが「ちょうど1秒の変わり目」に合わせて出す電気信号です。 1秒に1回、短い電圧の立ち上がりが出力されます。 位置情報とは無関係で、正確な時刻の基準として使われます。

GPSの時刻情報は通常、位置情報と同じ通信線（TX・RX）を通って文字データとして送られてきます。 しかしこの方法では、データが送られて処理されるまでの間に 数十ミリ秒から数百ミリ秒程度のずれが生じます。 PPS はこのずれを避けるための仕組みで、 時刻の変わり目そのものを1本の信号線で直接伝えます。 本システムで使用している GT-502MGG のデータシートによれば、 このパルス自体の精度は 30 ナノ秒（1億分の3秒）です。 文字データを解析する方法とは、精度が数万倍違います。

本システムでは、GPSモジュールの PPS 出力を Raspberry Pi の 12番ピン（GPIO18）へ接続しています。 Raspberry Pi は時計用の電池を持たず、計測中はインターネットにも接続しないため、 電源を入れ直すたびに内部時計がずれます。 CSVに記録される計測時刻はこの内部時計を使うため、 GPSから得られる正確な時刻で補正する必要があります。 PPS はそのための配線です。

なお、この配線を利用するには Raspberry Pi 側の設定が必要です。 配線を追加しただけでは時刻補正の精度は変わりません。

ピン番号の数え方

GPIO ヘッダは 2 列 20 段の合計 40 本のピンで構成されています。 1番ピンは基板の端にあり、そのピンだけ四角いはんだ面になっています。 1番ピンから見て、同じ列が奇数番（1・3・5…）、隣の列が偶数番（2・4・6…）です。 数え間違えると故障の原因になります。 作業前に必ず基板上の刻印で1番ピンの位置を確認してください。
