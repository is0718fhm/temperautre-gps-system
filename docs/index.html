水温・GPS計測システム

Raspberry Piを用いた水温・位置情報取得システム

概要 ハードウェア セットアップ 使用方法 CSVデータ トラブル

1. システム概要

本システムはRaspberry Piを中心として、 水温センサ（DS18B20）とGPSモジュールを用いて、 水温および位置情報をリアルタイム取得する計測装置です。

取得したデータはRaspberry Pi上のWebサーバで表示でき、 スマートフォンやPCからアクセスポイント経由で確認できます。

主な機能

  • 水温のリアルタイム計測
  • GPSによる緯度・経度取得
  • 現在位置の表示
  • 計測データのCSV保存
  • スマートフォンから操作可能
  • 電源投入時の自動起動

2. ハードウェア構成

部品 内容
Raspberry Pi 制御用コンピュータ
DS18B20 防水型温度センサ
GPSモジュール 緯度・経度・時刻取得
モバイルバッテリー 電源供給

3. 初期設定

Python環境

python3 -m venv env

source env/bin/activate

pip install flask
pip install pynmea2
pip install pyserial

センサ設定

DS18B20を1-Wire通信で接続します。 


sudo nano /boot/firmware/config.txt

dtoverlay=w1-gpio

GPS接続確認


ls /dev/serial*
GPSは /dev/serial0 を使用します。

4. 使用方法

起動


sudo systemctl start boat-monitor

Web画面表示

スマートフォンをRaspberry PiのWi-Fiへ接続後、 


http://raspberrypi.local:5000
へアクセスします。

5. CSVデータ

計測データはrecordsフォルダ内に保存されます。

項目 内容
time 計測時刻
temperature 水温(℃)
latitude 緯度
longitude 経度
fix GPS測位状態

6. トラブルシューティング

GPSが取得できない

  • アンテナを屋外へ向ける
  • /dev/serial0が存在するか確認
  • GPS Fixまで数分待つ

温度が取得できない

  • DS18B20の配線確認
  • w1モジュール確認

ls /sys/bus/w1/devices/
