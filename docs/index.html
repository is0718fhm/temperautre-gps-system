水温・GPS計測システム

取扱説明書

1. システム概要

本システムは、Raspberry Piを用いて水温と位置情報を計測する装置です。

取得したデータは、スマートフォンからWebブラウザで確認することができます。

主な機能

  • 水温のリアルタイム計測
  • GPSによる位置情報取得
  • スマートフォンからの操作
  • 計測データのCSV保存

2. ハードウェア構成

部品 役割
Raspberry Pi システム制御
DS18B20 水温測定
GPSモジュール 位置情報取得
バッテリー 電源供給

3. 使用方法

① 電源を入れる

本体へ電源を接続し、Raspberry Piを起動します。

② スマートフォンを接続する

スマートフォンのWi-Fi設定から、本システムのアクセスポイントへ接続してください。

③ Webページを開く

ブラウザで以下へアクセスしてください。

http://raspberrypi.local:5000

4. Web画面操作

表示内容

  • 現在時刻
  • 水温
  • 緯度・経度
  • GPS測位状態

計測開始

開始ボタンを押すと、データ保存を開始します。

計測停止

停止ボタンを押すと、データ保存を終了します。

CSV保存

計測結果はCSVファイルとして保存できます。

5. CSVデータについて

項目 内容
time 計測時刻
temperature 水温(℃)
latitude 緯度
longitude 経度
fix GPS測位状態

6. 注意事項

  • GPS取得には時間がかかる場合があります
  • GPSは屋外で使用してください
  • 水温センサの接続部は防水してください
  • 使用後は電源を切ってください
